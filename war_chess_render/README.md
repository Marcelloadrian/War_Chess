# War Chess - RENDER package
Stateless FastAPI run as a normal always-on web service; it also serves the static client from `public/`.

## Deploy (GitHub -> Render)
1. Push this folder to a GitHub repo (repo root = this folder). Add a .gitignore with `.venv/`, `__pycache__/`.
2. Render dashboard -> New -> Blueprint -> pick the repo (reads `render.yaml`).
   Manual alternative: New -> Web Service, Build `pip install -r requirements.txt`,
   Start `uvicorn api.index:app --host 0.0.0.0 --port $PORT`, env `PYTHON_VERSION=3.12.3`.
3. `WARCHESS_SECRET` is auto-generated by the blueprint. If you set it manually use a long random string
   and keep it identical on every instance.
4. Free plan sleeps after ~15 min idle: the first request then takes ~30-60 s. Saves are in the browser, so nothing is lost.

## First checks after deploy
- `https://YOUR-APP.onrender.com/api/new` returns JSON (also used as the health check).
- Play a few turns; "tampered or unsigned save" on every action means the secret changed between instances.

## Local run
    python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
    pip install -r requirements-dev.txt
    uvicorn api.index:app --reload --port 8000            # http://localhost:8000
## Test / balance
    pytest tests -q
    python tools/simulate.py 6      # difficulty + AI commander matrix (use 20 for reliable numbers)
## Game notes
Fog of war, scouts, naval pincers, fuzzy engagement intel, signed saves, no undo by design. See GDD.md.
Saves live in the browser (localStorage) and are HMAC-signed; set WARCHESS_SECRET in production.
Old saves are discarded automatically when the save format changes.
